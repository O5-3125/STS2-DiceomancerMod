# 乌鸦 crow
密林弱怪
低进阶20血，高进阶25血
乌鸦有两种行为模式：攻击和干扰。
如果敌人总数小于4 每回合意图固定为攻击模式，否则50%概率是干扰模式。如果上回合是干扰模式，这回合一定是攻击模式
攻击模式：先造成4点伤害，再造成1点伤害X次（X每次执行攻击意图后增加，单怪战初始是2，群怪时初始是0，当场上仅有一只乌鸦是上限是4，否则最高是6）
干扰模式：施加一层虚弱

# 鹅  goose
低进阶35血，高进阶40血
战斗开始时，鹅会获得特殊能力捣蛋鬼。
每回合，鹅会随机获得一种弃牌buff和一个攻击意图。
弃牌buff1：你打出任何牌后，弃掉你1张手牌，buff消失
弃牌buff2：你的下个回合开始时，弃掉你1张手牌，buff消失
前三回合攻击造成8伤害，4回合开始改为造成12点伤害

# 厚皮猪猪 piggy
低进阶75血，高进阶80血
战斗开始时，厚皮猪猪会获得1层[厚皮]。
厚皮猪猪有两种行动模式：拍肚皮和撞击，战斗开始时是拍肚皮模式，然后两种意图循环。
拍肚皮：获得2点力量，获得6层加固。
撞击：造成7点伤害，施加1层虚弱。

# 火猫三丈 cat
荣耀怪物
低进阶210血，高进阶220血
被动：玩家回合开始时手牌数字随机变化（变化规则写在下面）
每回合意图固定，造成4点伤害2次。
变化规则：对于一个数，先将其拆解为几个骰子，掷出骰子和后相加得出变化后的数
拆解规则：N=0，1，骰化结果为单个D4；对N>1，将2*N拆分为20，12，8，6，4的和（对于不小于4的偶数，这总是能做到的），使得骰子数尽可能的少，
且优先使用大骰子更多的组合。D20、D12、D8、D6、D4分别对应20，12，8，6，4，骰子组合即为这些数字组合
使用Scripts/Common/Utils/RandomCmd.cs获得随机数

# 海鸥 seagull
空图层召唤的小怪
50血
海鸥有五种行动模式：攻击、移除减益、塞薯条、加数字、给增益。海鸥被召唤时，会等概率的选择一个初始行动模式，然后按照前述顺序循环。每个行动模式都会产生恰好一个意图。 

攻击	造成3伤害3次
移除减益 移除所有友方的减益
塞薯条 加3张「薯条」到你的抽牌堆
加数字 所有友方的生命值和能力层数加2
给增益 所有友方获得2层力量

薯条：1费衍生状态牌 回复2点血量，消耗

# 黑色的鱼 blackfish
荣耀层boss
1000血
诅咒被动：玩家除第一回合外每回合开始要选择诅咒，比较复杂写在下面。
黑色的鱼有三个行动模式：重击,连击,buff。初始模式始终是重击，然后依前述顺序循环。

重击 造成20伤害
连击 造成5点伤害5次
buff 获得20层加固，获得2层力量

诅咒每次选择时从以下内容里抽X张让玩家选择Y项，X是Y的两倍，至少为3，至多为8，Y初始为1，每两回合增加1
诅咒选择可以参考游戏本体的知识恶魔（knowledge_demon）和本mod的抉择类型卡牌
诅咒内容：
对自己造成6点伤害。
失去5点生命。
失去10点最大生命值。
弃随机4张手牌。
对自身施加6层无力。
对自身施加2层虚弱。
对自身施加2层易伤。
对自身施加3层慌乱。
对自身施加3层缓慢。
对自身施加1层目盲。
加5张「虚空」到抽牌堆。
加3张「粘液」到手牌。
所有敌人获得3层力量。
所有敌人获得10层加固。


# 可爱的大手 Lizzy
2层精英
300血
每回合如果没有弃牌buff，获得弃牌buff
弃牌buff：当玩家打出10张牌后，丢弃玩家一半手牌，buff消失

可爱的大手有两种行动模式：大嘴巴子扇你和大嗓门使劲吼。战斗开始时处于大嘴巴子扇你，然后二者交替。

大嘴巴子扇你	造成12伤害 施加1层易伤

大嗓门使劲吼 造成4伤害3次 获得2点力量，施加3层负担

# 大红帽子怪 hat
2层怪物
低进阶70血，高进阶80血
被动：如果每回合打出的第一张牌目标不是他，获得3层闪避

大红帽子怪有两种行动模式：丢炸弹和准备炸弹。战斗开始，处于丢炸弹，然后两种模式交替。 

丢炸弹	获得丢炸弹buff，造成4伤害
丢炸弹buff：玩家打出不指向此敌人的卡牌时，加1张「烫手炸弹！」牌到你的手牌，当打出指向此敌人的卡牌时，buff消失
准备炸弹：造成6点伤害2次
烫手炸弹：1费衍生攻击牌 造成6点伤害，如果回合结束还在手牌中，对玩家造成6点伤害，消耗，虚无
